## TP 2 Notes

- In Part 2, we built the assigned Tangram by positioning all seven pieces with geometric transformations. We first placed the diamond with explicit matrix multiplication and then created `MyTangram` as a composite object to organize the remaining translations and rotations with `pushMatrix()`/`popMatrix()`.
- In Part 3, we implemented `MyUnitCube` as a single triangle mesh using the cube's 8 vertices and the corresponding indices for all faces. After that, we placed the cube behind the Tangram as a base and transformed the whole set so it became parallel to the XZ plane with the top-left corner at the origin.
- In Part 4, we created `MyQuad` as a unit square centered at the origin and used it to build `MyUnitCubeQuad`. The six faces of the cube were then generated by repeatedly displaying the same quad with the appropriate translations and rotations, replacing the previous mesh-based cube in the scene.
